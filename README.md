# Beauty Bot — Telegram-консультант салона косметологии

AI-консультант на Gemini. Бот расспрашивает клиента о проблеме кожи, предлагает подходящие процедуры с ценой «от …», называет специалиста и оформляет заявку. Заявки попадают в базу Netlify Blobs и в админ-панель. По желанию дублируются в Telegram администратору.

## Структура

| Путь | Что это |
|---|---|
| `netlify/functions/bot.mjs` | Вебхук Telegram (`/api/bot`) |
| `netlify/functions/admin.mjs` | API админ-панели (`/api/admin`) |
| `netlify/lib/ai.mjs` | Диалог с Gemini и создание заявки |
| `netlify/lib/store.mjs` | База (Netlify Blobs) и Telegram-хелперы |
| `netlify/lib/defaults.mjs` | Начальные услуги и специалисты |
| `public/` | Админ-панель |
| `scripts/poll.mjs` | Локальная проверка бота без деплоя |

## Переменные окружения

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от @BotFather |
| `GEMINI_API_KEY` | Ключ с https://aistudio.google.com/apikey |
| `ADMIN_PASSWORD` | Пароль входа в админ-панель |
| `GEMINI_MODEL` | Необязательно. По умолчанию `gemini-3.5-flash-lite` (быстрая) |
| `GEMINI_FALLBACK_MODEL` | Необязательно. Используется, когда у основной модели закончился лимит или она перегружена. По умолчанию `gemini-3.5-flash` |

> На бесплатном тарифе Gemini у каждой модели около 20 запросов в день. Одно сообщение клиента расходует 1–2 запроса. Для работы с реальными клиентами подключите оплату в Google AI Studio.

## Локальный запуск

```bash
npm install
npm run dev        # админка: http://localhost:8899
npm run poll       # в другом окне: пересылает сообщения бота на локальный сервер
```

`npm run poll` снимает вебхук. После проверки на опубликованном сайте нажмите в админке «Подключить бота к сайту».

## Публикация на Netlify

1. Создайте новый сайт из этой папки: `netlify deploy --prod` (или загрузите проект через GitHub).
2. В Netlify → Site configuration → Environment variables добавьте `TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY` и `ADMIN_PASSWORD`, затем выполните повторный деплой.
3. Откройте сайт и войдите с паролем. Перейдите в **Настройки** и нажмите **Подключить бота к сайту**.
4. Чтобы получать уведомления о заявках в Telegram, отправьте боту `/id` и вставьте число в поле «ID чата для уведомлений».

## Админ-панель

- **Заявки** — список заявок со статусами: Новая, Связались, Записан, Выполнена, Отменена. При статусе «Записан» бот может отправить клиенту подтверждение.
- **Специалисты** — имена, должности и опыт. Бот называет их клиенту.
- **Услуги** — названия, цены «от», длительность, описание и кто выполняет.
- **Настройки** — название салона, валюта, адрес, часы работы, чат для уведомлений.
